# Oratella releases

Desktop downloads of [Oratella](https://oratella.app/), which reads your EPUB, PDF, Word, Markdown and text files and web articles aloud.

- Windows 10 and 11 (64-bit): [oratella-setup.exe](https://github.com/brillianceappsfinland/oratella-releases/releases/latest/download/oratella-setup.exe)
- macOS 13 or later (Apple silicon and Intel): [oratella.dmg](https://github.com/brillianceappsfinland/oratella-releases/releases/latest/download/oratella.dmg)

How to install, including the first-launch step on a Mac: https://oratella.app/download.html

Questions: support@oratella.app
